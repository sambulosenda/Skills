# Skills

Custom Claude Code skills for React Native / Expo development.

## Installation

Clone this repo and symlink skills into `~/.claude/skills/`:

```bash
git clone https://github.com/sambulosenda/Skills.git ~/Skills

# Symlink a skill
ln -s ~/Skills/app-store-changelog ~/.claude/skills/app-store-changelog
```

## Skills

| Skill | Description |
|---|---|
| [app-store-changelog](./app-store-changelog) | Generate App Store / Play Store release notes from git history |
